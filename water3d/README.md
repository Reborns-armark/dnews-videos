# 作品「水が上がってくる世界」(縦型10秒・3D粘土・12fps・120フレーム)
1080x1920。water_render.py を `F_START=1 F_END=10 OUT_DIR=/tmp/out python3 water_render.py` で実行(pip install --break-system-packages bpy 後)。
- フレーム担当は各自の範囲のみレンダリングし、PNGを water3d/frames/ に push(ブランチ work-water3d)。
- 音は water3d/audio/ に wav(44.1kHz stereo)を push。
ストーリー: 1-21 寝てる粘土くんの周りに水たまり→22-32 目が覚めて驚く→33-70 木箱を積んで水位から逃げる→71-100 水が上がり木箱の塔の上で震える→101-120 引きで全景。
タイミング(12fps): f24=目を見開く, f40/48/56/64=木箱が出現して粘土くんが跳ぶ(各 +/-2フレームで着地), f68-84=震える/ドヤ, f100 水位が最大。

## 音の仕様(12fps: 時刻 t=(frame-1)/12 秒。全長10.0秒、44.1kHz stereo wav)
- f1-22(0-1.75s): 静かな寝息、水たまりがポタポタ。f12付近で小さな水滴音。
- f24(1.9s): 驚きのびっくり音(短い上昇グリス+「えっ!?」)。f27まで余韻。
- f28-38: 水がじわじわ上がるチャプチャプ音が少しずつ大きく。
- 木箱出現 f40,48,56,64 (3.25s,3.9s,4.6s,5.25s): 粘土の「ぽんっ」+跳ぶ「ぴょん」+着地「ぷにっ」。毎回少しピッチを変える。
- f68-90(5.6-7.4s): 震えて歯がカチカチ、水の低い唸りと波音がクレッシェンド。
- f94(7.75s): 水が止まる「ふぅ」の静けさ。f100(8.25s): 安堵の短い上昇音。
- f108(8.9s): ドヤ顔のジングル。f120(9.9s): 余韻でフェードアウト。
- 声は言葉にしない(ハミング/鳴き声/効果音のみ)。既存曲・既存音源は一切使わず、numpyなどで合成すること。
- 音楽(BGM): かわいいマリンバ/木琴/ピチカート風、約110BPM、sec 0-5 は穏やか→5-8 緊張(転調・半音で不安)→8.25から解決して明るく→10秒で切れ目なく終わる(最初の和音に戻れるとなおよい)。
